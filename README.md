# ASCIIModCoQ
Ever felt like you wanted to change the tileless mode font to a more terminal style? this mod accomplishes that!

This mod also fixes a few things absent currently in the game concerning abilities not showing their ASCII character when in tileless mode and disabling the modern projectile VFX.

Recommended: Use the mod here to replace ascii graphics more easily: https://steamcommunity.com/sharedfiles/filedetails/?id=3675780930&searchtext=easyascii

If all else fails try the following:

Setup:

1. Install UABEA Asset Ripper here https://github.com/nesrak1/UABEA/releases
2. Extract and and launch the .exe and open resources.assets, you can find it under CoQ_Data
3. Click "View" => "Filter" and select only Texture2D files, exit out of the filter window to apply
4. Find the Texture2D file named "Kobold_DynamicAtlas_Text_1", click "Plugins" => "Edit Texture" => "Load"
5. Inside the mod directory, open the file "RealHomosapien-ASCII"
6. Change Filter mode to Point and save
7. Exit out of UABEA and save when it asks
8. Done

In-Game: Just disable tile graphics and optionally modern UI

There is also a template for you if you wish to make your own font within the mod folder

Also found on Steam: https://steamcommunity.com/sharedfiles/filedetails/?id=3485963877
